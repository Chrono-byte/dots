# Noctalia v5

`config.toml` is the v5 native configuration. `palettes/Flexoki.json` carries over the previous dark palette. The old v4 configuration and plugins are retained under `legacy-v4/` as a reference because v5 is a new native shell and does not migrate v4 settings or Quickshell plugins. Reconfigure any plugin replacements in the v5 Settings UI.

The bar keeps the former launcher, active-window, media, workspace, clock, tray, notifications, battery, volume, and control-center layout. The v4 Tailscale and Zed-provider plugins are archived; they need v5/Luau-compatible replacements before they can return to the bar.
